# 獵人編年史：小傑篇 v0.1「離島之日」

非官方、非商業用途的單機網頁放置 RPG 原型。主角為小傑，劇情以《HUNTER×HUNTER》漫畫事件順序為主，2011 動畫作對照；台詞皆為遊戲重新撰寫，不逐字重製原作。

## 直接遊玩

雙擊 `index.html` 即可。遊戲不需要安裝、不需要後端、不需要網路連線。

## 初版內容

- 鯨魚島森林修行、採集與釣魚放置收益
- 「沼澤之王」放置拉鋸戰
- 米特道別事件
- 離島與船上風暴事件
- 雷歐力、酷拉皮卡初遇
- 船長動機問答
- 等級、體力、感知、體魄、意志、釣技、羈絆
- 背包、人物誌、時間線、旅程紀錄
- localStorage 自動存檔
- 存檔匯出 / 匯入
- 離線收益（最多計算 8 小時）
- 響應式手機版面

## 時間線範圍

v0.1 對應漫畫約第 1–2 話為主，並預告第 3–4 話的試驗前路線。後續版本可以沿著：

獵人試驗 → 揍敵客家族 → 天空鬥技場 → 返回鯨魚島 → 友克鑫 → 貪婪之島 → 嵌合蟻 → 會長選舉 / 小傑恢復

逐章擴充。

## 上線

這是純靜態網站，可直接部署到 GitHub Pages、Netlify、Cloudflare Pages、Vercel 等靜態網站服務。

## 素材說明

初版沒有熱連或打包官方動畫截圖。場景圖均為 `index.html` 內自製 SVG/CSS，以避免外部圖片失效與授權問題。之後若有自行取得授權或你提供的素材，可直接替換場景模組。
